# math.dev.br

Personal website of Matheus Alves, published with GitHub Pages from the `docs/` folder.

- `content.js`: all text, in English and Portuguese.
- `static/`: stylesheet and favicon.
- `build.js`: generates `docs/index.html` (English), `docs/pt/index.html` (Portuguese), the 404 page, sitemap, and `CNAME`.

```bash
node build.js
```
